Token 体系

所有数值的唯一真源是 kit/tokens/core.css。文档里的数值是为方便阅读的摘录，冲突时以该文件为准。

三层归位

Token 按作用域分三层，这个分层就是架构本身。

css
/* core   —— 跨形态通用 */
--color-accent: #8B3525;
/* forms  —— 形态级 */
--sidebar-width: 240px;
/* 组件内 —— 与组件同处 */
--code-keyword: #6B5B3E;
注意

不要从 Markdown 里手抄数值进代码。npm run check:tokens 会校验每个 var(--x) 都能解析到定义。

语义色

语义色是信息通道，不计入 accent 预算，但必须与文字标签同时出现。

Token亮色对暖白
--color-danger#5C1F2F10.90:1
--color-warning#7D5E125.30:1
--color-success#4F6B3A5.27:1
提示

四色两两最小色差 ΔE = 28，黑白复印后依然可分。
