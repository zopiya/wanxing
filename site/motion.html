全局样式 · Global

动效

温和流动。动效是为了让状态变化可被理解，不是为了让页面显得有活力。

四档强度

动效强度是页面级声明的，写在 data-motion 属性上， 而不是每个组件各自决定。这让"这个媒介不该有动效"变成结构上的事实而非约定。

等级名称含义典型场景
E8印刷静止完全无动效印刷品、PDF
E9-0静水仅状态反馈，无入场动画文档站、报告
E9-1春雨（默认）入场淡入上浮 + 编排网页、文章
E9-2微澜额外允许一处循环（品牌呼吸）品牌首页
 
<body data-motion="E9-1">

E8 在 CSS 里是硬关闭，不是约定：

[data-motion="E8"] *,
[data-motion="E8"] *::before,
[data-motion="E8"] *::after {
  animation: none !important;
  transition: none !important;
}

时长与缓动

Token值用途
--duration-instant80ms颜色变化
--duration-fast180ms悬停、焦点
--duration-base260ms浮层进出
--duration-slow420ms页面入场
--duration-crawl600ms总封顶
--ease-defaultcubic-bezier(.25,.1,.25,1)通用
--ease-outcubic-bezier(0,0,.2,1)入场
--ease-in-outcubic-bezier(.42,0,.58,1)仅限品牌呼吸

编排用 --stagger-1 到 --stagger-8，60ms 间隔，最多覆盖 8 个元素。 超过 8 个还要逐个入场，说明结构本身需要重新分组。

动效禁令

  • 旋转 spinner、弹跳、回弹、果冻、橡皮筋——与"温和流动"相悖
  • 循环 / 闪烁动效（品牌标识除外）——分散注意力
  • 单次位移 > 16px、时长 > 600ms——抢夺阅读
  • 视差滚动、滚动驱动的大面积运动
  • prefers-reduced-motion 下仍保留装饰动画
  • 用动画掩盖信息结构不清——动效不是结构问题的解药
没有加载动画，那怎么表示"正在加载"

用文字。"正在导出…"比一个转圈提供更多信息，而且不违反循环动画禁令。 骨架屏同样不做：静态的发丝线占位本质上就是一根线，而闪烁的 shimmer 是被禁的循环动画。 进度条也没有不确定态——那是换了个形状的 spinner。

完成信号

需要判断"页面动效是否播完"（截图、导出、自动化测试）时，引入 animations-complete.js，它会在全部动画结束后给 <html> 加上 data-animations-complete。

关键细节：getAnimations() 只看得见已经触发的动画。 滚动揭示尚未开始，所以任何延迟触发的动效都要向屏障登记：

window.__wxMotion.hold(myPromise);
