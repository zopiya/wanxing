Markdown 渲染

作者只写 Markdown；渲染层负责把标准 HTML 放进文心的排版、代码、表格与提示节奏中。

渲染预览

一段可以直接阅读的内容 #

普通段落不需要 class。行内 code、链接 和强调都保持正文节奏。

  • 列表保留语义和缩进。
  • 任务状态用原生 checkbox 表达：
    • 内容完成

Markdown 是内容格式；设计系统不应该要求作者知道组件 class。

<article class="wx-md wx-md--measured">
  <!-- renderer output -->
</article>
输入输出
## 标题带节奏与锚点的 h2
> 引用语义 blockquote
建议

保留渲染器原有 HTML；只在文章外层添加 wx-md。

接入契约

层负责什么不负责什么
作者写标准 Markdown 和有意义的 alt 文本。不写视觉 class，不复制组件结构。
渲染器生成标准 HTML、标题 id、图片与表格语义。不伪造图注、链接目的或内容状态。
文心样式提供 .wx-md、代码、表格、脚注、任务列表和提示块的呈现。不改变正文语义，也不覆盖真正组件的 class。

最短用法

<link rel="stylesheet" href="kit/index.css">
<article class="wx-md wx-md--measured">
  <!-- Markdown renderer output -->
</article>

Hugo、remark/rehype、markdown-it、VitePress 和 Docusaurus 都可以接入；区别只在渲染器如何产出锚点和提示块，样式层不绑定某一种工具。
