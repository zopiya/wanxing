价值观 · Values

设计价值观

七个维度定义了这套语言的坐标。其中三个是不变之魂，改动它们就不再是文心； 另外四个可变，正是它能适配不同媒介的原因。

七维度模型

维度取值含义
AA9 克制之美做减法，不做加法不变
BB9 温暖极简极简但不冷峻不变
CC9 温暖衬线正文用衬线，界面用无衬线可变
DD9 暖土调羊皮纸底 + 单一砖红不变
EE9 温和流动动效如春雨，不抢夺阅读可变
F输出形态网页 / 印刷 / 幻灯 / 报告…可变
GG2 东亚中文优先的排版与留白可变

A9 + B9 + D9 是不变之魂。任何改动触及这三条，产物就不再属于这套语言， 应当作为另一个设计系统对待，而不是这套的一个变体。

克制之美 · A9

克制不是少放东西，而是让每一个留下的东西都必须证明自己。 判据很具体：这个元素移除之后，读者会失去什么信息？如果答案是"没有"，它就该消失。

这条原则的直接产物是三条禁令：没有卡片、没有阴影、没有渐变。 它们不是审美偏好，而是同一个判据的结果——四边包围的方框、伪造的 z 轴纵深、 和色彩的连续过渡，都不携带信息。

克制的边界

克制之美从不以牺牲可达性为代价。对比度、焦点态、键盘可达、触控目标尺寸 这些都不参与哲学取舍——它们是无条件底线。一个看不清的界面不是克制，是失败。

温暖极简 · B9

极简很容易滑向冷峻：纯白底、纯黑字、无衬线、锐利直角。这套语言刻意避开了那条路。

底色是 #F2F0EB 的暖白，像羊皮纸而不像屏幕；正文是 #3A3837 的暖炭色， 从不使用纯黑；正文字体是衬线体。这些选择加起来产生的是"纸"的气质而不是"屏"的气质。

单一强调色 · D9

全页最多出现 两处 accent（图标激活态不计入）。这是整套系统被引用最多的约束。

理由是稀缺性：如果页面上有八个地方是红的，红色就不再意味着"看这里"。 像水墨画上的一枚朱砂印——其余全是黑白灰，它是唯一有温度的存在。频率越低，力量越大。

正文里的一个 链接 用的是墨色而不是 accent； 只有真正需要指向的那一处才配得上砖红。

品牌标记本身消耗一处预算。

四十分的现代惯例

这套语言大约 60% 是自己的设计思考，40% 是主流社区约定俗成的结构、色彩、排版、 动效、无障碍与形态契合。不为了哲学而哲学——表单就该长得像表单， 错误提示就该看起来像错误。

这 40% 不是妥协出来的，是由 双轨仲裁规则 三层结构产生的。
