接入

这套系统同时面向两类采用者：读文档的人，和读契约的 agent。两条路径分开走，因为它们需要的东西不一样。

两条路径

人需要知道为什么；agent 需要知道规则和怎么验证自己做到了。给 agent 一份三千行的双语散文不是接入，是转嫁工作。

给人用给 agent 用校验

装

npm install wenxin-wanxing
<link rel="stylesheet" href="node_modules/wenxin-wanxing/kit/index.css">

零运行时依赖，无构建步骤。产物不压缩——工程化问题排在系统本身完成之后。 许可证是 MIT。

哪些东西不随代码授出

MIT 覆盖代码与规范。朱砂印章 Logo 与 署名标记是品牌标识，不在其内—— 你可以使用这套设计语言，不要把它们当作自己的标识。边界见品牌应用。

适用范围，以及明确不适用的

这套语言为内容型产品而写：文档、文章、规范、作品集、轻量工具。 仪表盘、电商、CRM 明确在范围外——不是做不到，是它的取舍在那些场景下会持续和你作对。
