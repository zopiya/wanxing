Logo 设计规范

文心 · 万形的 Logo 是朱砂印章：实心底座、白色负空间和抽象几何，不是一个可随意换色的 UI 图标。

标准资产

网页示例只嵌入能独立呈现的朱砂印章。logo-mono.svg 保留 currentColor，外链 img 不会继承页面颜色；本站不直接嵌入它，小尺寸统一回到文字署名与 .wx-seal。

构造规则

元素固定规则原因
底座#8B3525 实心朱砂，rx="4"。像印章，有重量；不随深色模式换色。
负空间纯白 #FFFFFF，线宽 2.5px。品牌标识可比 UI 图标更重，但仍保持清晰。
几何圆角端点和转角；只用交汇、分叉、网络等抽象关系。表达思想和结构，不落入书本、齿轮、灯泡等具象套话。
最小呈现优先使用 SVG 原件；缩小到细节不可辨认时改用文字署名 ■。禁止模糊、投影或靠 PNG 补救。

使用边界

不要这样用

不要透明底、不要改成 1.5px 图标线宽、不要直角、不要给主 Logo 加深色模式变色逻辑，也不要把具象图标塞进印章内部。

可用资产位于 kit/assets/brand/：logo-wanxing.svg、logo-wenxin.svg、保留 currentColor 的 logo-mono.svg 与静态 brand-mark.svg。网页文字署名使用 CSS .wx-seal，它与 Logo 各司其职，不在同一品牌锁定中并列。
