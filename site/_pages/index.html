设计语言 · Design Language

文心 · 万形

文字即界面，留白即设计，克制即力量。
Text is the interface. Whitespace is the design. Restraint is the power.

这是一套以内容为中心的双语设计语言，同时提供规范与可直接复用的产物。 它不是一份说明文档：色彩、排版、间距、动效、组件、图表都以 CSS token 和组件的形式交付， 引一个文件就能用，不需要每次从哲学重新推导。

名字里有两层意思。文心是不变的魂——价值观与 token；万形是它在不同容器里呈现的形。 水没有自己的形状，但在任何容器里都还是水。

从哪里开始

  • 设计价值观 —— 这套语言相信什么，以及为什么
  • 双轨仲裁 —— 哲学与主流惯例冲突时听谁的
  • 全局样式 —— 色彩、排版、间距、动效、图标
  • 设计模式 —— 表单页、列表页、详情页怎么组织
  • 组件 —— 83 个类，含用法与源码

直接开始用

零运行时依赖，无构建步骤。引入一个文件即可：

<link rel="stylesheet" href="kit/index.css">

或者用打包好的单文件版本 kit/dist/wenxin.css——已展平所有 @import，不压缩。 需要行为增强（浮层、标签页、滚动揭示）时再按需引入 kit/components/js/ 里的脚本， 每一个都是渐进增强：没有 JS 时页面依然可读可用。

三条一以贯之的原则

减法优先

一个页面上每多一个视觉元素，读者就要多付一次注意力。装饰性的阴影、渐变、圆角卡片， 都在向读者收税，却不提供任何信息回报。能用留白解决的，不要用线；能用线解决的，不要用面。

状态绑定到无障碍树

所有组件状态一律走 ARIA 或原生属性——aria-current、aria-selected、 open、disabled——从不使用 .is-active 这类状态类。 这条规则是从"禁止仅用颜色区分状态"推导出来的：把 CSS 状态绑在无障碍树上， 就在结构上不可能出现读屏器感知不到的状态。

规则必须可执行

只写在文档里的规则不会被遵守。这套系统的每一条硬性约束都有对应的检查器： token 是否解析、对比度是否达标、是否出现了被禁的图形。npm run check 六项全绿才算数。

这条教训是付过学费的

审计矩阵曾经读错了一个字段，于是在每个页面都硬失败的情况下打印"0 failing"； 文字灰阶曾经有五个 token 不达 AA，最低到 1.54:1，而当时没有任何检查测量过 token 的数值。 一个不可能失败的检查比没有检查更糟，因为它的绿色会被当成证据引用。
