按钮 Button

默认是线框 ghost。每视图至多一个填充主按钮——约束是"限量"不是"禁止"。 CTA 优先用文字变体，"了解更多 →"比一个方框更符合这套语言。

何时使用、何时不用与 API

组件何时使用 · 不用契约
wx-page / wx-container / wx-measure页面底色、三档内容宽度、可读行长；不要在组件内再套页面容器。语义由内层 main/article/section 提供；宽度变体为 --article/content/showcase。
wx-stack / wx-cluster / wx-spread / wx-cols垂直节奏、可换行横组、两端信息、简单分栏；复杂布局写页面 grid。只负责布局，不改变 DOM 语义；紧/松变体是节奏，不是状态。
wx-rule章节或条目边界；能靠邻近表达时不加线。使用 hr；--short/strong 只用于明确层级。
wx-btn触发动作；导航目的地用 a。原生 button，唯一主操作可 --primary；危险动作 --danger 仍要确认文案。
wx-tag / wx-badge / wx-status短属性、计数、具名状态；长说明改用 note。状态必须有文字，不靠色彩；可点击时用 button/link 而非 span。
wx-avatar / wx-kbd / wx-seal人员标识、键盘提示、品牌印记；装饰头像/品牌不喧宾夺主。信息头像提供 alt/文本；纯装饰 seal 加 aria-hidden。
