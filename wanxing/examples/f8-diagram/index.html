F8 Diagram & Knowledge Map · 文心图解 · 2026

F8 文心图解用于交付可独立存在的关系图、流程图、架构图和知识地图。 它的核心不是装饰性插图，而是用文字、线条、节点和留白共同构成解释界面。 每张图解必须能在 3 秒内让读者识别核心关系和结构方向。

以下三张图解分别展示万形设计系统的架构层次、设计交付流程、 以及文心九形态与灵魂层的辐射关系。所有图解遵循 F8 规范： 1px 普通线条、1.5px 关键节点边框、暖土色调、Accent ≤ 2 处全页。

Diagram 01 壹 · 万形三层架构

Architecture（架构图）— 展示万形设计引擎的三层 Agent 架构。 Meta Agent 负责需求分析与分发，Wenxin Agent 执行设计产出，Audit Agent 进行多层审计。 虚线反馈回路连接审计结果与元编排层，形成持续迭代闭环。

架构图 · Architecture · 节点 5 · 连线 5

Diagram 02 贰 · 文心设计交付流

Flow（流程图）— 展示从用户需求到设计交付的完整流程。 包含意图推断、递归澄清、分发执行、HTML 产出、Render Contract 审计与多层审计环节。 两条反馈回路分别处理需求澄清与审计修复，形成双闭环交付体系。

Diagram 03 叁 · 文心九形态关系

Knowledge Map（知识地图）— 以文心灵魂层（A9 克制之美 · B9 温暖极简 · D9 暖土调）为核心， 辐射出九个输出形态（F1–F9）。每个形态标注其适用场景，线条连接示意派生关系。 灵魂层是不可妥协的圆心，形态层随容器而化。
