# 多层审计 Prompt 模板

> 本文件包含截图视觉审计与动效运行时审计 prompt。视觉 prompt 可直接喂给多模态模型；动效 prompt 结合 Render Contract JSON、CSS 静态指标和 Playwright `document.getAnimations()` 运行时采样使用。

---

## 粗筛 Prompt（5 项）

粗筛用于快速扫描页面整体质量，5 项全部通过才进入细磨阶段。

### 1. 整体调性

- **对应准则**：C-1（哲学-视觉一致）、C-2（色彩-情感一致）
- **Prompt**：

  请观察这张页面的整体视觉感受，回答以下问题：

  1. 页面是否给人"安静、克制、温暖"的第一印象？还是"喧闹、花哨、冰冷"？
  2. 页面中是否存在以下视觉噪声：装饰性阴影、渐变背景、彩色色块、圆角超过 8px 的元素、填充色按钮？
  3. 色彩基调是否以暖白/暖灰/深炭为主？是否出现了高饱和的蓝、绿、紫、橙色？
  4. 如果去掉所有文字，仅看色块和留白，页面是否仍然感觉"干净"？

- **判定标准**：
  - ✅ 通过：安静、温暖、无视觉噪声
  - ⚠️ 警告：有 1 处轻微噪声（如一个小阴影），但不影响整体
  - 🔴 阻断：多处视觉噪声，或高饱和色大面积出现，完全偏离文心调性

### 2. 灵魂层保护

- **对应准则**：M-1（拒绝拟物）、D9（暖土调）
- **Prompt**：

  请检查页面是否存在以下"灵魂层违规"：

  1. **拟物化元素**：皮革纹理、木纹背景、缝线效果、金属拉丝、3D 按钮、毛玻璃过度使用（backdrop-filter blur > 12px）
  2. **禁用色彩**：高饱和蓝色（如 `#3B82F6`）、高饱和绿色（如 `#22C55E`）、高饱和紫色（如 `#8B5CF6`）、高饱和橙色（如 `#F97316`）
  3. **渐变背景**：任何线性渐变或径向渐变背景
  4. **纯白/纯黑滥用**：大面积使用 `#FFFFFF` 代替暖白 `#F2F0EB`，或 `#000000` 代替深炭 `#3A3837`

  请逐一回答"是"或"否"，并标注违规元素的位置。

- **判定标准**：
  - ✅ 通过：无任何灵魂层违规
  - 🔴 阻断：存在拟物化元素、高饱和色、渐变背景中的任一项

### 3. 留白呼吸感

- **对应准则**：P-3（留白即设计）
- **Prompt**：

  请观察页面的留白密度，回答以下问题：

  1. 页面大区块（如 Hero 区与正文区、两个章节之间）的间距是否感觉"充裕"？视觉上是否 ≥ 80px 感知间距？
  2. 段落之间的间距是否明显大于行高？（视觉上段落间距应 ≥ 行高的 1.5 倍）
  3. 页面内容是否"挤在一起"？是否存在多个元素紧贴边缘、缺少内边距的情况？
  4. 当觉得"间距是不是太大了"时，是否仍然感觉舒适？（文心的留白密度极高，大区块间距从 96px 起步）

- **判定标准**：
  - ✅ 通过：留白充裕，区块间距 ≥ 80px 视觉感知
  - ⚠️ 警告：部分区域留白偏紧（如 40-60px），但不影响阅读
  - 🔴 阻断：内容拥挤，区块间距 < 32px，缺少呼吸感

### 4. Accent 克制

- **对应准则**：D9（暖土调 — Accent ≤ 2 处）
- **Prompt**：

  请统计页面中砖红色（`#8B3525` 或暗色模式下 `#C4533E`）作为强调色出现的次数：

  1. 找出所有使用砖红色的元素（文字、边框、背景、图标、下划线等）
  2. 统计独立出现次数（同一元素 hover 态不算额外次数）
  3. 排除以下不算次数的场景：图标激活态、选中态、品牌标识符 `■`
  4. 总数是否 ≤ 2 处？

  请列出每个 accent 元素的位置和用途。

- **判定标准**：
  - ✅ 通过：accent 出现 ≤ 2 处（不含激活/选中态）
  - ⚠️ 警告：accent 出现 3-4 处，但均为小面积使用
  - 🔴 阻断：accent 出现 ≥ 5 处，或大面积 accent 背景色块

### 5. 排版层级

- **对应准则**：P-2（层次清晰）
- **Prompt**：

  请观察页面的文字层级是否清晰：

  1. 页面是否只有一个 `<h1>` 标题？
  2. 标题（h1/h2/h3）与正文之间是否有明显的字号和字重差异？（标题字号应 ≥ 正文的 1.5 倍）
  3. 用户能否在 3 秒内识别页面上最重要的文字元素？
  4. 是否存在多个元素使用相同的大字号/粗体，导致"谁更重要"不明确？
  5. 辅助文字（日期、元数据、版权）是否明显弱于正文？（字号更小、颜色更浅）

- **判定标准**：
  - ✅ 通过：层级清晰，3 秒内可识别最重要元素
  - ⚠️ 警告：层级基本清晰，但有 1-2 处权重模糊
  - 🔴 阻断：多个元素争夺同一视觉权重，无法区分主次

## 细磨 Prompt（11 条）

细磨阶段对每条准则进行精确审计。

### C-1 哲学-视觉一致

- **类别**：visual+context
- **Prompt**：

  你是一个文心设计语言的审计员。请观察这张页面，逐项检查以下视觉特征是否能被"克制之美"的哲学解释：

  1. **边框**：页面中的边框是否极细（1px）且颜色为暖灰？是否存在粗边框（>2px）或彩色边框？
  2. **圆角**：按钮和输入框的圆角是否 ≤ 4px？是否存在 > 8px 的大圆角或全圆角（pill shape）？
  3. **阴影**：页面中是否存在 `box-shadow`？文心禁止装饰性阴影。
  4. **装饰元素**：是否存在分割线以外的装饰性线条、图标、花纹？
  5. **按钮**：按钮是否为线框型（透明背景 + 1px 边框）？是否存在填充色按钮（实心背景色）？

  对每一项回答"通过"或"违规"，违规项请标注具体位置和视觉表现。

- **检查要点**：
  - 每个视觉特征（边框/圆角/阴影/装饰/按钮）都能追溯到"克制之美"
  - 无法被哲学解释的元素 = 装饰 = 违规
- **常见问题**：
  - 卡片使用 `box-shadow: 0 2px 8px rgba(0,0,0,0.1)` 制造浮起感
  - 按钮使用 `background: #8B3525; color: white` 填充型
  - 圆角 `border-radius: 12px` 或 `9999px`（pill shape）
  - 装饰性分割线使用波浪线或点线

### C-2 色彩-情感一致

- **类别**：visual
- **Prompt**：

  请评估页面的色彩基调是否传达"温暖、安静、克制"的情感：

  1. 主背景色是否为暖白色调（偏黄/偏棕的白），而非冷白色调（偏蓝的白）？
  2. 文字色是否为暖调深色（偏棕的黑），而非纯黑 `#000000`？
  3. 整体色彩是否以中性色（白/灰/棕）为主，强调色占比 < 5%？
  4. 如果这是一个内容型网站（博客/文档/作品集），色彩是否让内容成为主角？还是色彩本身在抢夺注意力？

- **检查要点**：
  - 背景色温：暖白 `#F2F0EB` 而非冷白 `#F0F4F8`
  - 文字色温：深炭 `#3A3837` 而非纯黑
  - 强调色占比：目测 < 5% 页面面积
- **常见问题**：
  - 使用 Tailwind 默认的 `bg-gray-50`（冷灰）代替暖白
  - 使用 `text-black` 或 `#000000` 作为正文色
  - 大面积蓝色导航栏或绿色 CTA 按钮

### C-6 色彩语义角色

- **类别**：mixed
- **Prompt**：

  请检查页面中语义色 token 的使用是否正确：

  1. **Accent（砖红 `#8B3525`）**：是否仅用于强调/链接 hover/激活态？是否被用作错误提示色？
  2. **文字层级**：
     - 主文字 `--color-text-primary`（`#3A3837`）是否用于正文？
     - 辅助文字 `--color-text-secondary`（`#888580`）是否用于日期/元数据？
     - 弱化文字 `--color-text-muted`（`#B0ABA4`）是否用于版权/占位符？
  3. **边框层级**：
     - 细边框 `--color-border-subtle`（`#E5E1DA`）是否用于常规分隔？
     - 强边框 `--color-border-strong`（`#C8C3BA`）是否仅用于表头/强调分隔？
  4. 是否存在 accent 色被复用于 error/warning/success 语义的情况？

- **检查要点**：
  - 每个语义色 token 只用于其语义目的
  - accent ≠ error（文心没有独立的 error 色，错误用 accent + 文字说明）
- **常见问题**：
  - 表单错误使用红色 `#EF4444` 而非 accent 色
  - 成功提示使用绿色 `#22C55E`
  - 所有文字都用同一颜色，没有 secondary/muted 层级

### M-1 拒绝拟物

- **类别**：visual
- **Prompt**：

  请检查页面是否存在以下拟物化（Skeuomorphic）元素——这些是 2010 年代的设计遗产，在 2026 年已被淘汰：

  1. **纹理背景**：纸张纹理、木纹、皮革纹理、布料纹理、噪点纹理（noise texture）
  2. **拟物图标**：3D 图标、带阴影的图标、模拟物理物品的图标（如真实信封、真实文件夹）
  3. **3D 效果**：`box-shadow` 模拟凸起/凹陷、`inset` 阴影模拟内凹、渐变模拟金属光泽
  4. **毛玻璃过度**：`backdrop-filter: blur()` 值 > 12px，模拟磨砂玻璃效果
  5. **手写体/装饰字体**：用于正文的装饰性字体（标题展示字体除外）

  对每一项回答"存在"或"不存在"，存在请标注位置。

- **检查要点**：
  - 任何模拟物理材质的装饰 = 违规
  - 例外：如果明确标注为"复古风格"的有意选择，标记为 ⚠️ 警告而非 🔴 阻断
- **常见问题**：
  - 背景使用 `background-image: url('paper-texture.png')`
  - 按钮使用 `box-shadow: inset 0 1px 0 rgba(255,255,255,0.3)` 模拟凸起
  - 使用 `backdrop-filter: blur(20px)` 的大面积毛玻璃导航栏

### M-4 无障碍底线

- **类别**：mixed
- **Prompt**：

  请检查页面是否满足 WCAG 2.2 AA 无障碍底线（阻断性准则）：

  1. **文本对比度**：
     - 正文文字与背景的对比度是否 ≥ 4.5:1？
     - 大号文字（≥18px bold 或 ≥24px regular）与背景的对比度是否 ≥ 3:1？
     - 辅助文字（灰色元数据）与背景的对比度是否 ≥ 4.5:1？
  2. **焦点状态**：
     - 所有可交互元素（链接、按钮、输入框）在 focus 时是否有可见的焦点指示器？
     - 焦点指示器是否未被 `outline: none` 移除？
  3. **颜色不单独传递信息**：
     - 错误状态是否同时使用颜色 + 文字说明（或图标）？
     - 是否仅靠颜色区分状态（如仅用红色表示错误，无文字说明）？
  4. **触控目标**（移动端）：
     - 所有交互元素的触控区域是否 ≥ 44×44px（iOS）或 ≥ 48×48px（Android）？

  请逐项回答"通过"或"违规"。

- **检查要点**：
  - 对比度：正文 ≥ 4.5:1，大字 ≥ 3:1
  - 焦点：`:focus-visible` 始终可见
  - 信息传递：颜色 + 文字/图标，不纯靠颜色
- **常见问题**：
  - `--color-text-muted`（`#B0ABA4`）在暖白底上对比度约 2.8:1，不达标
  - 链接使用 `outline: none` 并自定义了不可见的 focus 样式
  - 表单错误仅用红色边框，无错误文字说明

### P-1 黄金比例参考

- **类别**：mixed
- **Prompt**：

  请检查页面的字号阶梯和间距系统是否遵循一致的比例因子：

  1. **字号阶梯**：
     - 相邻字号的比值是否接近 1.250（Major Third）或 1.333（Perfect Fourth）？
     - 是否存在"随意"的字号值（如 15px、19px）无法追溯到阶梯系统？
  2. **间距系统**：
     - 垂直间距是否基于 4px 或 8px 网格？
     - 是否存在任意像素间距（如 `margin: 13px`、`padding: 7px`）？
  3. **内容宽度**：
     - 正文行宽是否在 60-75 字符（拉丁文）或 30-40 字符（CJK）范围内？
     - 内容最大宽度是否 ≤ 640px（阅读型）或 ≤ 760px（列表型）？

  请标注发现的 ad-hoc 值及其位置。

- **检查要点**：
  - 字号来自阶梯：11/13/16/17/20/24/30/36/48/72px
  - 间距来自 4px 网格：4/8/12/16/20/24/32/40/48/64/96/128px
  - 无 ad-hoc 像素值
- **常见问题**：
  - 使用 `font-size: 15px`（不在阶梯中）
  - 使用 `margin: 15px` 或 `padding: 18px`（非 4px 倍数）
  - 正文内容宽度 `max-width: 800px`（超出阅读型推荐值）

### P-2 层次清晰

- **类别**：visual
- **Prompt**：

  请评估页面的视觉层次是否清晰：

  1. **3 秒测试**：不看文字内容，仅看视觉权重，能否在 3 秒内识别页面上最重要的元素？
  2. **层级数量**：页面上的对比层级是否 ≤ 3 级？（如：标题 = 强、正文 = 中、元数据 = 弱）
  3. **区分手段**：层次是否通过字号 + 字重 + 色彩 + 间距的组合来建立？还是仅靠单一手段（如仅靠颜色）？
  4. **竞争元素**：是否存在两个或多个元素使用相同的大字号/粗体/强调色，导致"谁更重要"不明确？

- **检查要点**：
  - 3 秒内可识别最重要元素
  - 对比层级 ≤ 3 级
  - 层次通过多手段组合建立
- **常见问题**：
  - 标题和 CTA 按钮使用相同的字号和颜色，争夺注意力
  - 所有文字使用同一字号，仅靠颜色区分层级
  - 侧边栏导航与正文标题使用相同的字重

### P-3 留白即设计

- **类别**：visual
- **Prompt**：

  请精确评估页面的留白密度：

  1. **大区块间距**：相邻大区块（如 Hero → 正文 → Footer）之间的垂直间距是否 ≥ 80px 视觉感知？文心推荐 96px（`--space-24`）起步。
  2. **段落间距**：段落之间的间距是否 ≥ 行高的 1.2 倍？（中文行高 1.85，段落间距应 ≥ 20px）
  3. **内容区留白**：内容区域周围（左右两侧）是否有充足的留白？（至少等于内容宽度的 20%）
  4. **元素内边距**：卡片/引用块/代码块的内边距是否 ≥ 16px？是否存在内容紧贴边框的情况？
  5. **移动端留白**：在窄屏下，留白是否被过度压缩？（移动端大区块间距可降至 56px，但不应 < 32px）

- **检查要点**：
  - 大区块间距 ≥ 80px（推荐 96px）
  - 段落间距 ≥ 20px
  - 内容区左右留白 ≥ 内容宽度的 20%
  - 元素内边距 ≥ 16px
- **常见问题**：
  - Hero 区与正文区间距仅 32px
  - 引用块 `padding: 8px`，文字紧贴边框
  - 移动端大区块间距压缩至 16px

### P-4 对比有目的

- **类别**：visual
- **Prompt**：

  请检查页面中每一处显著对比是否服务于信息层级：

  1. **字号对比**：大字号与小字号的差异是否对应到不同的信息重要性？（如标题 vs 正文）
  2. **字重对比**：粗体与常规字重的差异是否用于强调关键信息？还是随意使用？
  3. **色彩对比**：深色与浅色的差异是否用于区分主文字与辅助文字？
  4. **间距对比**：大间距与小间距的差异是否用于区分内容区块的独立性？
  5. **无目的对比**：是否存在为了"好看"或"有设计感"而添加的对比？（如装饰性大字号、无意义的颜色变化）

  对每一处显著对比，请说明它服务于什么信息层级。

- **检查要点**：
  - 每处对比都能对应到信息层级
  - 对比层级 ≤ 3 级
  - 无"为了好看"的装饰性对比
- **常见问题**：
  - 装饰性的大字号引言，与内容层级无关
  - 随机使用不同颜色的文字制造"视觉丰富感"
  - 同一层级的列表项使用不同的字号

### P-5 行长与行高

- **类别**：visual+approx
- **Prompt**：

  请估算页面的行长和行高是否符合阅读舒适标准：

  1. **行长（Line Length）**：
     - 中文正文每行是否约 30-40 个字符？
     - 英文正文每行是否约 60-75 个字符？
     - 是否存在行长过长（>50 中文字符或 >90 英文字符）导致阅读疲劳？
  2. **行高（Line Height）**：
     - 中文正文行高是否 ≥ 1.6？（视觉上，行间距应约为字号的 0.6-0.85 倍）
     - 英文正文行高是否 ≥ 1.5？
     - 标题行高是否更紧凑（1.2-1.45）？
  3. **段落间距**：段落之间的间距是否明显大于行高？（视觉上应有"断开"感）

  请估算具体数值并判断是否在推荐范围内。

- **检查要点**：
  - 中文行长 30-40 字符，英文 60-75 字符
  - 中文行高 ≥ 1.6（推荐 1.85），英文 ≥ 1.5
  - 标题行高 1.2-1.45
  - 段落间距 > 行高
- **常见问题**：
  - 全宽正文无 `max-width` 限制，行长 > 80 中文字符
  - 中文正文 `line-height: 1.4`，阅读拥挤
  - 标题使用 `line-height: 2.0`，过于松散

### A-1 WCAG 对比度

- **类别**：mixed
- **Prompt**：

  请检查页面的色彩对比度是否满足 WCAG 2.2 AA 标准（阻断性准则）：

  1. **正文对比度**：主文字色（`#3A3837`）与背景色（`#F2F0EB`）的对比度是否 ≥ 4.5:1？
     - 预期值：`#3A3837` on `#F2F0EB` ≈ 12.4:1 ✅
  2. **辅助文字对比度**：辅助文字色（`#888580`）与背景的对比度是否 ≥ 4.5:1？
     - 预期值：`#888580` on `#F2F0EB` ≈ 4.6:1 ✅（临界）
  3. **弱化文字对比度**：弱化文字色（`#B0ABA4`）与背景的对比度是否 ≥ 3:1？
     - 预期值：`#B0ABA4` on `#F2F0EB` ≈ 2.8:1 ❌（不达标，仅可用于装饰性文字如版权）
  4. **暗色模式对比度**：暗色模式下文字与背景的对比度是否同等达标？
     - `#E8E3DC` on `#1A1816` ≈ 11.8:1 ✅
  5. **UI 组件对比度**：边框、图标等 UI 组件与背景的对比度是否 ≥ 3:1？

  请标注不达标的具体色值组合。

- **检查要点**：
  - 正文 ≥ 4.5:1（WCAG AA）
  - 辅助文字 ≥ 4.5:1
  - 弱化文字 ≥ 3:1（仅用于非关键信息）
  - UI 组件 ≥ 3:1
- **常见问题**：
  - 自定义浅色文字（如 `#CCCCCC`）在暖白底上对比度仅 1.6:1
  - 暗色模式下 accent 色未调整，对比度不足
  - 浅灰色边框 `#E5E1DA` 在暖白底上对比度仅 1.3:1（可接受，因为边框不是信息载体）

### A-2 焦点指示器

- **类别**：mixed
- **Prompt**：

  请检查页面中所有可交互元素的焦点指示器：

  1. **链接**：Tab 导航到链接时，是否有可见的焦点环或下划线变化？
  2. **按钮**：Tab 导航到按钮时，是否有可见的焦点环？
  3. **输入框**：Tab 导航到输入框时，是否有可见的焦点边框？
  4. **焦点环样式**：
     - 是否使用 `outline: 2px solid --color-focus; outline-offset: 2px`？
     - 焦点环对比度是否 ≥ 3:1 与相邻颜色？
  5. **`:focus-visible`**：是否仅在键盘导航时显示焦点环（`:focus-visible`），而非鼠标点击时也显示？
  6. **`outline: none` 滥用**：是否存在 `outline: none` 且未提供替代焦点样式的情况？

  请逐一检查并标注缺失焦点指示器的元素。

- **检查要点**：
  - 所有交互元素有可见焦点指示器
  - 焦点环 ≥ 2px，对比度 ≥ 3:1
  - 使用 `:focus-visible` 而非 `:focus`
  - 无 `outline: none` 滥用
- **常见问题**：
  - 全局 `* { outline: none; }` 移除所有焦点环
  - 自定义焦点样式使用 `box-shadow` 但颜色太浅（对比度 < 3:1）
  - 仅使用 `:focus` 导致鼠标点击时也显示焦点环

## 审计结果分级

| 级别 | 符号 | 含义 | 处理方式 |
|------|------|------|---------|
| 阻断 | 🔴 ❌ | 严重违背文心灵魂层（A9/B9/D9）或 WCAG 2.2 AA 底线 | 自动标记阻断，建议 Meta 重分 Wenxin 修正 |
| 警告 | ⚠️ | 主观判断，存在歧义，或临界值 | 列出问题 + 选项，交给用户决策 |
| 建议 | 💡 | 可改进但不阻塞流程 | 纳入改进建议列表，不阻塞交付 |

### 分级判定规则

- **阻断触发条件**（满足任一项即阻断）：
  - 灵魂层违规：拟物化元素、高饱和色大面积使用、渐变背景
  - Accent 滥用：≥ 5 处 accent 出现
  - WCAG 2.2 AA 不达标：正文对比度 < 4.5:1
  - 无焦点指示器：交互元素缺失焦点状态
  - 留白严重不足：大区块间距 < 32px

- **警告触发条件**：
  - Accent 出现 3-4 处
  - 辅助文字对比度临界（4.0-4.5:1）
  - 部分区域留白偏紧（40-60px）
  - 层级有 1-2 处权重模糊

- **建议触发条件**：
  - 可优化但非必须：如字体加载策略、container queries 使用
  - 美学提升：如垂直节奏微调、标点挤压

## 暗色模式检查要点

暗色模式不是简单反转，而是重新定义调色板。请逐项检查：

1. **色温保持**：
   - 背景是否为暖暗色（`#1A1816`）而非纯黑（`#000000`）或冷暗色（`#111827`）？
   - 文字是否为暖象牙白（`#E8E3DC`）而非纯白（`#FFFFFF`）？

2. **Accent 映射**：
   - 亮色模式 accent `#8B3525` 是否正确映射为暗色模式 `#C4533E`（略亮以保持感知亮度）？
   - 暗色模式下 accent 对比度是否 ≥ 3:1（UI 组件）？

3. **边框可见性**：
   - 暗色模式下边框是否仍然可见但不过于突兀？
   - `--color-border-subtle`（`#2E2B27`）在暖暗色底上是否可辨识？

4. **语义色适配**：
   - 辅助文字 `--color-text-secondary`（`#8A857D`）在暗色模式下对比度是否 ≥ 4.5:1？
   - 弱化文字 `--color-text-muted`（`#5A5550`）是否仅用于非关键信息？

5. **代码块/引用块**：
   - 暗色模式下代码块背景 `--color-bg-subtle`（`#2A2724`）是否与主背景有微妙区分？
   - 语法高亮是否切换为暖色调暗色方案（关键字 `#C4533E`、字符串 `#C4A87A`）？

6. **图片适配**：
   - 暗色模式下图片是否添加了微妙的亮度降低（避免过亮刺眼）？
   - 图注文字在暗色模式下是否仍然可读？

## Motion Runtime Prompt

### M-R1 春雨润物

- **对应规范**：`.opencode/rules/motion-spec.md`
- **输入**：Render Contract motion 字段、CSS 静态动效指标、`document.getAnimations()` 运行时采样、截图前后状态。
- **Prompt**：

  请作为文心动效审计员，判断这个页面的动效是否符合“春雨润物，细节有声”：

  1. 动效是否服务于状态反馈、阅读转换、主题切换、loading 或品牌细节？是否存在为了展示技巧而存在的动画？
  2. duration 是否全部 ≤ 600ms？品牌标识符 4s 呼吸是否是唯一装饰性循环？
  3. 位移是否 ≤ 16px，常规进场是否接近 6-8px？
  4. 是否存在 rotate、bounce、spring、elastic、强回弹、强视差？
  5. `prefers-reduced-motion` 是否能关闭装饰性动画？
  6. `data-animations-complete` 是否在截图前进入 `true`？
  7. 运行时采样中的动画数量、最长时长、循环状态是否与 contract 声明一致？

- **判定标准**：
  - ✅ 通过：动效轻微、服务明确、运行时与 contract 一致。
  - ⚠️ 警告：动效参数合规，但存在气质是否过度的主观疑点。
  - 🔴 阻断：出现超长、超距、旋转、弹跳、非例外循环、缺少 reduced motion 或 completion signal。
