前言

文心设计语言

文心 (Wenxin) 是一套以「文字即界面，留白即设计，克制即力量」为核心命题的设计语言。它诞生于一个简单的观察：当代数字产品的界面越来越喧哗，而最好的阅读体验往往是最安静的——一本纸质书、一张信笺纸、一份铅字排版的文档。

文心设计语言由两个层次构成。第一层是「灵魂」——色彩系统、字体哲学、留白密度、点睛之色、动效节奏——在任何场景、任何产品类型中永不妥协。第二层是「形态」——布局结构、导航形式、内容组织方式——如同水随容器而变，跟随该类型产品的行业 UX 最佳惯例。

《万形书卷》是文心设计语言的印刷版呈现。在九种输出形态 (F1–F9) 中，F4 文心书卷是唯一使用 E8 印刷静止的形态——没有动效，没有暗色模式，没有交互状态。所有信息通过字号、字重、间距、色彩的静态组合传达。这是文心最纯粹、最接近其哲学本源的形态。

本书采用 Van de Graaf 经典版面确定页面边距，使用 pt（点）作为印刷字号单位，提供完整的 CMYK 色彩映射。它既是一本设计规范手册的示范，也是一件可以直接交付印刷的排版作品。

适用范围

文心设计语言适用于以内容/信息为核心的产品：博客、个人网站、知识库、文档站、作品集、简历、Landing Page、轻量工具。不适用于数据密集型 Dashboard、电商、游戏、娱乐类产品。

七个维度

文心设计语言对应七个维度的固定值：A9 克制之美、B9 温暖极简、C9 温暖衬线、D9 暖土调、E9 温和流动（印刷时为 E8 静止）、F1–F9 九种输出形态、G2 东亚文化语境。其中 A9、B9、D9 是不变之魂，任何演化不可偏离。

第一章

设计哲学

核心命题

内容本身是最重要的视觉主体。所有 UI 决策服务于同一目标：让用户最自然、最安静地进入内容——而不是被界面打断。用户感受到的不是「风格统一」，而是「说不出的舒服」。这就是润物细无声。

水的原则 · 两层结构

这套设计语言的本质是水。水的本质 (H₂O) 不因容器而改变，但在杯子里是杯子的形，在河道里是河道的形。灵魂永远不变——色彩系统、字体哲学、留白密度、点睛之色、动效节奏。形态随境而化——布局结构、导航形式、内容组织方式跟随产品类型惯例。

三项灵魂原则

减法优先 (Reduction First)

任何元素若无法让内容更清晰，就不应存在。没有装饰阴影，没有多余边框，没有视觉噪声。印刷排版天然克制——每增加一条线、一个符号，都需要回答：这服务于什么目的？

克制的惊喜 (Restrained Surprise)

动效的存在如同书页翻动时纸张的阻力：你感到用心，但不会停下来欣赏它。在印刷中，这种克制体现为首字下沉和结尾装饰——它们是章节的呼吸节拍，而非炫耀技巧。

点睛之色 (Accent as Focal Point)

全页只允许一个强调色（砖红 #8B3525 — PANTONE 7621 C），它是整个设计的灵魂签名。就像水墨画里的朱砂印章——其他一切是黑白灰，它是唯一有温度的存在。频率越低，力量越大。全页出现不超过两处。

「色彩不是装饰，是承诺。每增加一种颜色，就稀释了其他颜色的力量。」

适用与不适用

文心适用于以内容/信息为核心的产品。在以数据密度和操作效率为优先的场景中（如金融 Dashboard、电商后台），克制的排版哲学可能阻碍信息获取，需要更高密度和更强功能色的设计语言。

F4 书卷特有的设计决策

印刷是文心设计语言的原乡。衬线字体的笔画起伏在印刷页面上比屏幕上更自然——因为衬线字体本就是为印刷而生的。暖白底色 (C3 M3 Y6 K0) 本质上是一种纸张颜色——它映射到未涂布纸张的视觉质感。砖红强调色映射到朱砂——东亚传统印刷中最具标志性的色彩。

第三章

九种输出形态

文心设计语言支持九种正式输出形态 (F1–F9)。每种形态在保持灵魂层 (A9/B9/D9) 不变的前提下，适配各自媒介的排版和交互惯例。

F1 · HTML Web — 文心正典

响应式网站，暗色模式就绪。内容宽度使用 clamp() 实现流体响应式。此为文心最完整的形态，所有 Token 定义的基准参照。

F2 · Mobile App — 文心移动

原生或混合移动应用。触控目标 ≥ 48pt，安全区域适配刘海屏与底部手势条。字号阶梯适配移动端，但正文不低于 16px。动效映射触觉反馈。

F3 · Brand Identity — 文心品牌

Logo 系统、品牌色彩、视觉识别。核心是朱砂印章 Logo — 砖红底座、纯白冲压线条、2.5px 线宽、4px 微圆角。品牌标识符 ■ 紧随品牌名，全页唯一。

F4 · Print & Editorial — 文心书卷 ← 本书

印刷排版。pt 单位、CMYK 色彩映射、Van de Graaf 版面。唯一使用 E8 印刷静止的形态 — 无动效、无暗色模式。适用于书籍、论文、杂志、诗集、Zine。

F5 · Presentation — 文心演示

16:9 幻灯片。展示优先字号 (14px–88px)，六种幻灯片类型（标题/章节分隔/纯文字/文字+图片/引用/结尾）。构建动画使用温和缓动，每张标题 ≤ 30 字。

F6 · Documentation — 文心文档

双栏布局文档站。侧边栏 240px + 内容区。暖色调语法高亮（棕/金/红/灰，禁止冷色调蓝/绿/紫）。增强代码块、提示框、版本选择器。

F7 · Poster & Cover — 文心海报

单页强视觉表达。六种画布比例（2:3/3:4/1:1/16:9/4:3/A系列），四种构图模式。单页 Accent 可放宽：标题 + 署名各 1 处 = ≤ 2 处。

F8 · Diagram & Knowledge Map — 文心图解

架构图、流程图、知识地图。SVG 独立交付，Mermaid 转译规则。拓扑审计：线条不穿字、关系方向 3 秒可识别。禁止 Mermaid 默认彩虹色块。

F9 · Report & LaTeX Typesetting — 文心报告

Markdown → LaTeX → PDF 的判断型报告。核心章节：执行摘要、发现、建议。F9 复用 F4 的印刷 Token 但不承担书籍出版系统。

形态上限

文心正式输出形态固定为 F1–F9，不再扩张。Newsletter、Dashboard、电商、游戏、复杂 CRM 不进入正式形态。
