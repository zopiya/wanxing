01 · 设计哲学

灵魂三原则

文心设计语言的核心命题，适用于所有形态，永不妥协。

原则一

文字即界面

内容本身是最重要的视觉主体。所有 UI 决策服务于同一目标：让用户自然、安静地进入内容，而不是被界面打断。

原则二

留白即设计

留白不是空缺，是设计的一部分。足够的留白让内容呼吸、让层次清晰。空间本身就是一种无声的语言。

原则三

克制即力量

全页只有一个强调色，一个品牌标识符。出现越少，力量越大。如同水墨画里的朱砂印章 — 稀少才有分量。
