三大原则
— 文字即界面 — 内容是最重要的视觉主体，所有UI决策服务于让用户自然进入阅读
— 留白即设计 — 大区块间距 ≥ 96px，当觉得「太空了」时往往才是对的
— 克制即力量 — 全页强调色 ≤ 2 处，出现越少，力量越大
