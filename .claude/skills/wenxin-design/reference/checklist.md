# 交付前自查

按顺序过。任何一条不确定，去 `kit/wenxin.json` 查，不要凭印象。

## 第一层 · 无条件（两轨都适用）

- [ ] 每个前景色对**它实际落在的那个面**过 WCAG 2.2 AA，不是只对页面底色
- [ ] 焦点态可见：≥2px，对比 ≥3:1，**没有任何 `outline: none`**
- [ ] 全部交互元素键盘可达，焦点顺序合理
- [ ] 触控目标 Web ≥24px / iOS ≥44pt / Android ≥48dp（视觉尺寸和命中盒是两件事）
- [ ] 没有任何状态**只靠颜色**区分
- [ ] `prefers-reduced-motion` 下动效退化
- [ ] 有 `<main>` 地标；每个表单控件有关联 label；每个交互元素有可访问名

## 轨道

- [ ] 这一页声明了 `track`
- [ ] 如果它是原型 E（工具 / 表单），轨道已翻转为**应用轨**
- [ ] 页内的数据录入与反馈组件按惯例处理（第三层），无论轨道

## 阅读轨的视觉约束

- [ ] 没有四边包围的容器（边框 / 阴影 / 填充 + 圆角）——分组用单边线和留白
- [ ] 没有 `box-shadow`、没有渐变
- [ ] 强调色出现 **≤2 次**（品牌印章算一次）
- [ ] 没有填充按钮，**除非**它是这一视图唯一的主操作
- [ ] 边框 ≤1px，`--stroke-mark` 的 1.5px 除外
- [ ] 没有 spinner、骨架屏、自动轮播、装饰插画

## 数值

- [ ] 所有数值来自 token，没有硬编码的 hex / px
- [ ] 每个 `var(--x)` 都能解析（`npm run check:tokens`）
- [ ] 间距落在 4px 网格上
- [ ] 中文行长 ≤36em

## 结构

- [ ] 每页恰好一个 `<h1>`，标题不跳级
- [ ] 状态用 ARIA / 原生属性，**没有 `.is-active` 这类状态类**
- [ ] 类名 `wx-` 前缀，只有一层 `__`
- [ ] 标签配平——一个游离的 `</div>` 能让半页塌掉，而多数检查看不见

## 最后

- [ ] `npx wenxin audit <file>` 通过（`hardGates` 为空）
- [ ] 上面那四条**需判断**的规则，逐条想过并能说出理由
- [ ] 未做完或有矛盾的地方**写下来**，不要抹平
