# 禁用清单 · Forbidden List

> 属于 [wenxin](./README.md) 灵魂层 — Soul layer

这是灵魂层的禁令——跨一切形态都成立。形态特有的禁令（演示文稿禁止 > 80 字/页、印刷禁止 7pt 以下文字）见对应的 [wanxing](../wanxing/README.md) 形态文件。

These prohibitions hold across every form. Form-specific prohibitions (presentations forbid >80 characters/slide, print forbids sub-7pt text) live in the corresponding wanxing form file.

| 禁止 Forbidden | 原因 Reason |
|------|------|
| 卡片 + 阴影 Cards + shadows | 制造不必要的视觉层级 creates unnecessary visual hierarchy |
| 渐变色背景 Gradient backgrounds | 破坏气质 breaks the temperament |
| 高饱和色（蓝/绿/紫/橙）High-saturation blue/green/purple/orange | 只允许一个 Accent only one accent is allowed |
| 填充色圆角按钮 Filled rounded buttons | 引入过多产品感 too much "product" feel |
| 纯装饰性图片 Purely decorative images | 仅内容型图片 only content imagery |
| 粗边框（> 1px）Thick borders (> 1px) | 视觉噪声 visual noise |
| 色块背景分区 Color-block section dividers | 用留白分区 use whitespace instead |
| 填充型图标 Filled icons | 仅线条型 stroke only |
| 两个图标库同页混用 Two icon libraries on one page | 描边风格不一致 stroke personality clashes |
| 循环/闪烁动效 Looping/flashing animation | 分散注意力（品牌标记和 loading 除外）distracting (except brand mark and loading) |
| Accent 出现超过 2 次 Accent appears more than twice | 稀少才有力量（图标激活态除外）rarity is power (except icon active state) |
| 大段正文居中对齐 Centered long-form body text | 伤害可读性 hurts readability |
| 连续超过 3 个长段落不插锚点 3+ long paragraphs with no anchor | 读者会感到压迫 reader feels crowded |
| 同区块字号层级过于接近 Type sizes too close within a block | 失去呼吸感 loses breathing room |
| `outline: none` | 破坏键盘可访问性 breaks keyboard accessibility |
| 仅颜色区分交互状态 Color-only state distinction | 色盲用户无法感知 imperceptible to colorblind users |
| 链接文字为「点击这里」Link text "click here" | 无语义，屏幕阅读器无法理解 no semantic meaning |

四个最常被违反的 AI 设计套路，额外强调：**无阴影。无填充按钮。无渐变。无「圆角卡片+彩色左边框+图标」组合。**

The four most commonly violated AI-design tropes, worth repeating: **no shadows. No filled buttons. No gradients. No rounded-card-with-colored-left-border-and-icon.**
