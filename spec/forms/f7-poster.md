# F7 · Poster & Cover

> 属于 [spec](../README.md) 形态层 — Form layer
> 轨道 Track：`editorial` · 动效 Motion：**印刷版 `E8` / 数字版 `E9-1`** · 画布 Canvas：`poster`

## 身份与边界 · Identity

F7 交付**单页强视觉画布**：活动海报、书籍封面、专辑封面、数字横幅、宣传单页、展览主视觉。

> **海报是"克制之美"在单页尺度上的最强表达。克制不是"什么都不放"，而是"只放必须放的"。**
> Restraint is not "putting nothing" — it is "putting only what must be there."

与 F3 的边界：**F3 是识别系统，F7 是应用。** F3 定义 logo 长什么样，F7 把它放进一张画布。
**封面归 F7，不归 F4。**

## 画布比例 · Canvas Ratios

| 比例 | 基准尺寸 | 用途 |
|---|---|---|
| 2:3 | 1200×1800 | 书籍封面、竖版海报（标准） |
| 3:4 | 1200×1600 | 竖版海报、宣传单页 |
| 1:1 | 1200×1200 | 专辑封面、社交头像 |
| 16:9 | 1920×1080 | 横幅、社交头图 |
| 4:3 | 1600×1200 | 横版海报 |
| A 系列 | A4 / A3 / A2 / A1 | 印刷海报（ISO 216） |

**出血**：印刷 3mm，数字版不需要。

## 四种构图 · Composition Modes

| 模式 | 说明 | 适用 |
|---|---|---|
| 居中对称 | 全部元素垂直 + 水平居中 | 活动海报、书籍封面 |
| 左对齐 | 文字组左对齐，居上 1/3 或下 2/3 | 宣传单页、学术海报 |
| 对角分布 | 主标题居上，署名/日期在右下 | 展览海报、专辑封面 |
| 全出血文字 | 极大字号标题占满画布 | 极简海报、品牌海报 |

## 排版 · Typography

**展示优先，极大字号。** 标题用 `--font-display`（Lora）。
中文标题字距舒展 `--tracking-chinese` `0.1em`。

## accent —— 本形态的规则与 Web 不同

**F7 的 accent 预算是「标题 1 处 + 署名 1 处」，标题可以使用 accent。**

这不是放宽，是同一条约束在不同画布语义下的正确解释：
一张海报的"全页"就是一张画布，而一个 Web 页面的"全页"可能有十屏高。
总量仍然 ≤2，只是分配方式不同。**标题用 accent 是海报的点睛。**

审计器按形态分派预算，不走 `allowedDeviations` —— 因为它本来就合规。
判定记录见 [DECISIONS.md](../DECISIONS.md) **D-5**。

## 动效 · Motion —— 按交付介质分岔

**F7 是唯一一个动效强度取决于交付介质的形态：**

| 交付介质 | 强度 | 说明 |
|---|---|---|
| 印刷海报 | **E8** | 与 F4 一致，完全静止 |
| 数字海报 / 横幅 | **E9-1** | 单次进场 fade-up 420ms，**无循环** |

渲染契约需声明 `canvas.printOnly: true|false`，审计器据此选择规则集。
判定记录见 [DECISIONS.md](../DECISIONS.md) 待判定项。

## 社交卡片变体 · Social Card

小红书等社交长图属于 F7 的子形态：固定 3:4 或 1:1，字号进一步放大，
安全区按平台 UI 遮挡范围收紧。
