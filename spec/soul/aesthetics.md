# 当代美学准则 · Modern Aesthetics Criteria

> 属于 [spec](../README.md) 灵魂层 — Soul layer
> 这是[双轨仲裁](../tracks.md)中「40% 主流惯例」的主要来源，也是审计的准则依据。

## 这份文件的作用 · What this is for

[philosophy.md](./philosophy.md) 定义文心**想成为什么**。这份文件定义它**必须达到什么** ——
34 条来自当代设计共识的可审计准则，五个维度，每条都以"回答是或否"的形式给出检查方法。

Philosophy defines what Wenxin *wants to be*. This file defines what it must *clear* —
34 auditable criteria drawn from contemporary design consensus.

**两条标记为阻断性（M-4、A-1）的准则不达标即不可交付**，不提供"有条件通过"。

---

## 一、一致性 Coherence（C-1 … C-7）

每一处视觉选择都要能被追问"这服务于什么目的"。

| | 准则 | 检查 |
|---|---|---|
| **C-1** | 哲学-视觉一致 | 每个视觉特征（边框粗细、圆角、装饰）都能追溯到[核心命题](./philosophy.md)？存在无法被哲学解释的装饰吗？ |
| **C-2** | 色彩-情感一致 | 色彩基调传达的情感与内容类型和受众预期一致？ |
| **C-3** | 排版-内容一致 | 行高、字重、字号阶梯与内容密度和阅读场景匹配？有排版选择反而让内容更难读吗？ |
| **C-4** | 动效-交互一致 | 动效强度与输出形态的交互需求匹配？<br>**反例**：在 F2 移动端用 E8 印刷静止 —— 用户得不到任何触控反馈 |
| **C-5** | 排版阶梯一致 | 所有字号都来自定义的阶梯？存在 ad-hoc 像素值吗？需要"特殊字号"时应扩展阶梯而非硬编码 |
| **C-6** | 色彩语义角色 | 每个语义色 token（accent / danger / success / warning）**只用于其语义目的**？<br>**存在 primary accent 被复用为 error 色的情况吗** |
| **C-7** | 动效调色板一致 | 所有时长与缓动来自定义的动效 token？存在 ad-hoc 过渡值吗？ |

> **C-6 是本次重构补齐语义色的直接依据** —— 准则假设 danger/success/warning 存在，
> 而旧 token 里只有 accent。见 [color.md](./color.md) 与 [../tracks.md](../tracks.md)。

## 二、当代性 Modernity（M-1 … M-9）

| | 准则 | 检查 |
|---|---|---|
| **M-1** | 拒绝拟物 | 无模拟物理材质的装饰（皮革、木纹、缝线、金属拉丝、3D 效果）？<br>例外：哲学明确选择复古为核心命题时，须标注为有意选择 |
| **M-2** | 暗色模式就绪 | 定义了完整的暗色映射（背景/前景/强调色/语义色）？暗色下有对比度不足或色彩失真吗？<br>暗色模式不是可选功能，是操作系统的标准能力 |
| **M-3** | 可变字体优先 | 优先可变字体，或给出使用固定字重的理由？加载了过多固定字重吗？ |
| **M-4** | **无障碍底线 —— 阻断性** | 见第五节 A-1…A-4，任何一项不达标即阻断交付 |
| **M-5** | 响应式必须 | 320px → 2560px 全程有意设计？导航、图片、表格在各断点有明确适配？存在只在桌面端成立的设计吗？ |
| **M-6** | 可持续设计 | 尊重 `prefers-reduced-motion`？图片用现代格式、字体已子集化？存在不必要的动画或过大资源吗？ |
| **M-7** | 现代布局优先 | container queries 优先于全局视口断点；`auto-fit/auto-fill + minmax()` 优先于固定列数；`clamp()` 流体间距优先于固定值 |
| **M-8** | 字体性能 | `font-display: swap` 是底线；关键字体 preload；**CJK 字体必须按 `unicode-range` 子集化** |
| **M-9** | 感知均匀色彩 | 暗色映射与渐变使用 OKLCH 而非 sRGB？存在 sRGB 插值产生的灰色中间带吗？ |

> **M-6 与 M-8 共同支持了字体自托管的决定** —— 第三方字体 CDN 既不利于性能碳足迹，
> 也让 F4/F7 的印刷输出无法离线复现。

## 三、比例与层次 Proportion & Hierarchy（P-1 … P-7）

| | 准则 | 检查 |
|---|---|---|
| **P-1** | 比例基准 | 字号阶梯与间距系统遵循一致的比例因子（1.250 Major Third / 1.333 / 4px 网格）？存在随意值吗？ |
| **P-2** | 层次清晰 | 标题→副标题→正文→辅助信息的层级视觉可辨？**读者能在 3 秒内识别最重要的元素**？有多个元素争夺同一视觉权重吗？ |
| **P-3** | 留白即设计 | 内容区周围留白 ≥ 行高的 0.5 倍？区块之间有明显留白分隔？<br>留白量应与内容密度成反比 |
| **P-4** | 对比有目的 | 每一处显著对比都对应一个信息层级？**页面上对比层级不超过 3 级**？存在为"好看"而加的无目的对比吗？ |
| **P-5** | 行长与行高 | 行长：拉丁 60–75 字符 / **CJK 30–40 字**；行高：拉丁 1.5–1.7 / **CJK 1.6–1.8** |
| **P-6** | 垂直节奏 | 所有垂直间距来自 spacing token，基于一致基数（4px）？存在任意像素值吗？ |
| **P-7** | 动效时长比例 | 时长随元素大小与位移缩放？**小元素（按钮、开关）≤150ms，大元素（页面、模态）≥200ms** |

## 四、文化敏感度 Cultural Sensitivity（S-1 … S-6）

文心的 G 维度取值为 **G2 东亚**，但准则本身要求这个选择是**有意识的**，而非默认的。

| | 准则 | 检查 |
|---|---|---|
| **S-1** | 色彩文化 | 目标文化语境已明确，色彩在该语境中得体？<br>红色在东亚是喜庆、在西方是危险；白色在东亚传统关联丧事、在西方关联婚礼 |
| **S-2** | 排版文化 | CJK 排版规范（行高、标点挤压、避头尾）已遵循？ |
| **S-3** | 图标文化 | 图标隐喻在目标文化中可读？ |
| **S-4** | 色彩文化标记 | 文化敏感色彩已被显式标记并说明理由？ |
| **S-5** | 跨文化图标审查 | 面向多文化受众时，图标已做跨文化审查？ |
| **S-6** | RTL 布局支持 | 若需支持从右至左语言，布局逻辑属性（`margin-inline` 等）已就位？ |

> **砖红 `#8B3525` 的选择正是 S-1 与 S-4 的正面案例**：它取自朱砂印章，
> 在 G2 东亚语境中是文人与信物的意象，这是一个有出处、被显式声明的选择。
> 见 [brand.md](./brand.md)。

## 五、无障碍与舒适度 Accessibility & Comfort（A-1 … A-5）

**这一节整体构成[双轨仲裁](../tracks.md)的第一层全局底线** —— 不分形态、不分轨道，无条件生效。

| | 准则 | 要求 |
|---|---|---|
| **A-1** | **对比度 —— 阻断性** | 正常文本 ≥4.5:1；大文本（18px bold 或 24px regular 以上）≥3:1；**UI 组件与图形对象 ≥3:1**。任何一项不达标 = 阻断 |
| **A-2** | 焦点指示器 | 所有可交互元素有可见焦点态；面积 ≥1 CSS px 环绕元素；对比 ≥3:1；**永不被 `outline: none` 移除**（WCAG 2.2 §2.4.11-13） |
| **A-3** | 减少动效尊重 | 响应 `prefers-reduced-motion`；该模式下非功能性动画移除，**必要的状态转换反馈仍保留**；持续性 loading 指示器是唯一例外 |
| **A-4** | 最小触控目标 | Web ≥24×24px（§2.5.8）/ iOS ≥44pt / Android ≥48dp |
| **A-5** | APCA Lc — 信息性 | 建议正文 APCA Lc ≥60。**此条不阻断交付**，作为 WCAG 对比度的补充通道 |

## 如何使用 · How to use

1. **设计时** —— 当哲学与惯例冲突，先查 [../tracks.md](../tracks.md) 的三层规则；这份文件提供惯例一侧的具体依据。
2. **审计时** —— `scripts/render-audit.mjs` 自动检查其中可机器判定的部分（对比度、焦点态、token 一致性、动效时长、触控尺寸）；其余需人工过一遍。
3. **争议时** —— 用编号引用（"这违反 C-6"），比"感觉不对"精确得多。判定结果记入 [../DECISIONS.md](../DECISIONS.md)。

**任何一条准则的"不达标"都应被显式记录，而不是悄悄绕过。**
这套体系的惯例是坦白地标注缺口，而不是把它抹平。

This system's convention is to flag gaps candidly rather than smooth them over.
