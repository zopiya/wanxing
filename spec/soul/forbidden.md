# 禁用清单 · Forbidden List

> 属于 [spec](../README.md) 灵魂层 — Soul layer
> 分轨说明 Track scope：见 [../tracks.md](../tracks.md)。标 **[双轨]** 的两轨都禁；标 **[阅读轨]** 的在应用轨有条件放宽。

这是灵魂层的禁令，跨一切形态成立。形态特有的禁令（幻灯片禁止 >80 字/页、印刷禁止 <7pt 文字）
见对应的[形态文件](../forms/DECISIONS-MATRIX.md)。

---

## 一、容器与层级 · Containers & Hierarchy

| 禁止 | 原因 | 轨 |
|---|---|---|
| **卡片式容器** —— 指四边包围的方框（边框 / 阴影 / 填充底色**三者任一** + 圆角），用来把一组内容"装起来" | 制造不必要的视觉层级 | **[阅读轨]** |
| 阴影 `box-shadow` | 伪造 z 轴纵深，与平面克制相悖 | **[双轨]** |
| 色块背景分区 | 用留白分区 | **[阅读轨]** |
| 粗边框（>1px，`--stroke-mark` 的 1.5px 描边除外） | 视觉噪声 | **[双轨]** |

> **允许的替代**：单边分隔线 + 留白构成的条目 —— `wx-entry`。
> 见 [components.md](./components.md)。
>
> **旧措辞「卡片 + 阴影」已废弃**：它含糊到可以被理解为"只禁止两者的组合"。
> 现在禁的是**几何形状**，不是那个名词。
>
> **应用轨的有条件放宽**：iOS 分组列表等平台惯例可用 `wx-list--grouped`，
> 走边框实现，**仍然禁止阴影**。

## 二、色彩 · Color

| 禁止 | 原因 | 轨 |
|---|---|---|
| 渐变色背景 | 破坏气质 | **[双轨]** |
| 高饱和色（蓝/绿/紫/橙）作为**装饰或强调** | 只允许一个 accent | **[双轨]** |
| accent 出现超过 2 处（图标激活态除外） | 稀少才有力量 | **[阅读轨]** |
| 仅用颜色区分交互状态 | 色盲用户无法感知 | **[双轨]** |
| 把 accent 复用为 error 色 | 违反 [aesthetics.md](./aesthetics.md) **C-6**：语义色只有一个功能 | **[双轨]** |

> **语义色不在此列**。`--color-danger` / `--color-success` / `--color-warning`
> 是[双轨仲裁第一层](../tracks.md)要求的信息通道，不计入 accent 预算，也不算"高饱和装饰"。
> 但它们必须**与文字说明同时使用**，颜色不可单独承载信息。

## 三、按钮与交互 · Buttons & Interaction

| 禁止 | 原因 | 轨 |
|---|---|---|
| 填充色按钮 —— **每视图至多一个 `wx-btn--primary` 例外** | 引入过多产品感 | **[限量]** |
| `outline: none` | 破坏键盘可访问性 | **[双轨]** |
| 链接文字为「点击这里」 | 无语义，屏幕阅读器无法理解 | **[双轨]** |

> 旧规范把主提交按钮写成括号里的例外。现在它是一等变体，
> 约束从"禁止"改为"**限量**"：默认 ghost 线框，每视图至多一个填充主按钮。

## 四、图标与图像 · Icons & Imagery

| 禁止 | 原因 | 轨 |
|---|---|---|
| 填充型图标 | 仅线条型 | **[双轨]** |
| 两个图标库同页混用 | 描边风格不一致 | **[双轨]** |
| 纯装饰性图片 | 仅内容型图像 | **[双轨]** |
| 拟物材质（皮革、木纹、缝线、金属拉丝、3D） | [aesthetics.md](./aesthetics.md) **M-1** | **[双轨]** |

## 五、动效 · Motion

| 禁止 | 原因 |
|---|---|
| 循环/闪烁动效（品牌标识与 loading 除外） | 分散注意力 |
| 旋转 spinner、弹跳、回弹、果冻、橡皮筋 | 与"温和流动"相悖 |
| 单次位移 >16px、duration >600ms | 抢夺阅读 |
| 视差滚动、滚动驱动的大面积运动 | 同上 |
| `prefers-reduced-motion` 下仍保留装饰性动画 | [aesthetics.md](./aesthetics.md) **A-3** |
| **用动画掩盖信息结构不清** | 动效不是结构问题的解药 |

完整清单见 [motion.md](./motion.md)。

## 六、排版 · Typography

| 禁止 | 原因 |
|---|---|
| 大段正文居中对齐 | 伤害可读性 |
| 连续 >3 个长段落不插锚点 | 读者感到压迫 |
| 同区块字号层级过于接近 | 失去呼吸感 |
| ad-hoc 字号与间距（不在 token 阶梯内） | [aesthetics.md](./aesthetics.md) **C-5 / P-6** |

## 七、数据可视化 · Data Visualization

| 禁止 | 替代 |
|---|---|
| 饼图 / 环形图 | 排行条，或 ≤3 段占比堆叠 |
| 雷达图 / 蛛网图 | 小倍数 |
| 仪表盘 / 速度表 | 数字 + 一句话 |
| 3D 任何形式 | 二维 |
| 词云 | 排行条 |
| 树图 / 按面积编码的气泡图 | 面积编码不可靠 |
| 双 Y 轴 | 两张小图 |
| 渐变填充、阴影、圆角柱帽 | 见第一、二节 |
| 用色相区分序列 | 墨色阶梯 + 线型，见 [data-viz.md](./data-viz.md) |
| 裸图表（无标题、无量纲说明） | 图表必须有编辑型框架 |

> 这一节多数条目是既有禁令**应用到新媒介**的结果，而非新增约束。

---

## 四个最常被违反的 AI 设计套路

额外强调，因为模型在无约束时几乎必然产出它们：

**无阴影。无填充按钮。无渐变。无「圆角卡片 + 彩色左边框 + 图标」组合。**

**No shadows. No filled buttons. No gradients. No rounded-card-with-colored-left-border-and-icon.**

---

## 可执行性 · Enforcement

`npm run check:forbidden` 对 `kit/` 与 `examples/` 做静态检查：
`box-shadow`（非 `none`）、`linear-gradient` / `radial-gradient`、
超出 `--stroke-mark` 的边框宽度、弹跳类缓动、填充按钮计数。

**这份清单不是风格建议，是构建会失败的检查项。**
